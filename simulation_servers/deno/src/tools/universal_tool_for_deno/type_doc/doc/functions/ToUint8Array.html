    函数 ToUint8Array

    • ToUint8Array(data: any): Promise<Uint8Array<ArrayBufferLike>>

      将各种 JavaScript 二进制数据类型统一转换为 Uint8Array。

      支持的数据类型：

      1. Uint8Array
      2. Node.js Buffer
      3. ArrayBuffer
      4. SharedArrayBuffer
      5. DataView
      6. Int8Array
      7. Uint16Array
      8. Int16Array
      9. Uint32Array
      10. Float32Array
      11. Float64Array
      12. 其他 TypedArray
      13. 普通 Array（number[]）
      14. String（UTF-8 编码）

      参数

      • data: any

        需要转换的数据。

      返回 Promise<Uint8Array<ArrayBufferLike>>

      转换后的字节数组。

      抛出

      不支持的数据类型。

      抛出

      普通 Array 中包含无效字节值。

      示例

      const bytes: Uint8Array = await ToUint8Array(data);
